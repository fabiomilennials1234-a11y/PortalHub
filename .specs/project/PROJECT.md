# PortalHub — Visao Geral do Projeto

## Produto

PortalHub = plataforma all-in-one de comunidades + cursos online. Clone Skool.com com UX world-class, gamificacao nativa, e integracao futura com ecossistema milennials.

## Objetivo

MVP funcional em 16 semanas (8 sprints de 2 semanas). Criadores criam comunidades, publicam cursos, cobram assinaturas, e engajam membros via gamificacao.

## Stack

Next.js 15 + Supabase + Stripe + Tailwind 4 + shadcn/ui. Ver `.specs/codebase/STACK.md`.

## Escopo MVP

**Entra**: Auth, Profiles, Organizations, Community Feed, Courses, Gamificacao, Payments, Notifications, Events, Moderation basica.

**Fora**: Live streaming, quizzes, certificados, analytics avancado, white-label, app mobile, AI features.
