# PortalHub — Stack Tecnologica

## Runtime

- Node.js 20 LTS
- TypeScript 5.5+ (strict: true)

## Frontend

- Next.js 15 (App Router, React Server Components, Server Actions)
- React 19
- Tailwind CSS 4
- shadcn/ui + Radix UI primitives
- Framer Motion (animacoes)
- TanStack Query v5 (server state)
- Zustand (client state)
- React Hook Form + Zod (forms + validacao)
- Tiptap (rich text editor)
- next-themes (dark mode)

## Backend

- Supabase (PostgreSQL 15+, Auth, Realtime, Storage, Edge Functions)
- Next.js API Routes (webhooks, logica complexa)
- Next.js Server Actions (mutations)

## Pagamentos

- Stripe (Checkout, Billing Portal, Subscriptions API, Webhooks)

## Email

- Resend + React Email

## Video

- Embed externo (YouTube, Vimeo, Loom) — MVP
- Mux ou Cloudflare Stream — v2

## Deploy

- Vercel (Next.js)
- Supabase Cloud (backend)

## Testes

- Vitest (unit + integration)
- Playwright (E2E)
- Supabase local (docker-compose pra integration tests)

## CI/CD

- GitHub Actions (lint, typecheck, test on PR)
- Vercel (preview deploys, production)

## Monitoring

- Sentry (error tracking)
- Vercel Analytics (usage)
