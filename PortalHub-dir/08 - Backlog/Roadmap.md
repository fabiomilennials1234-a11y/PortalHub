# Roadmap

## MVP (v1) — 16 semanas

- Auth + Profiles + Organizations
- Community Feed (posts, comments, reactions, categories)
- Courses (modules, lessons, video embed, progress tracking)
- Gamificacao (points, levels, achievements, leaderboard)
- Payments (Stripe subscriptions, free/paid tiers)
- Events (calendar, RSVP, external meeting links)
- Notifications (in-app realtime, email)
- Basic Moderation (reports, ban, hide/delete)
- Admin Dashboard (members, engagement, revenue)

## v2 — Pos-MVP

- Live Streaming (Mux ou Cloudflare Stream)
- Quizzes e Assessments
- Certificados (PDF + verificacao)
- Analytics Avancado (cohort, funnel, heatmaps)
- Mobile App (React Native ou PWA)
- Asaas integration (PIX, boleto — mercado brasileiro)
- Sub-comunidades
- AI Features (resumos, recomendacoes, moderacao auto)
- Video hosting nativo (Mux)
- i18n (PT-BR + EN)
- Email digest e template builder

## v3 — Futuro

- White-label (dominio customizado, branding per org)
- API Marketplace
- Integracoes (Zapier, n8n, Torque CRM)
- Enterprise features (SSO, audit log avancado, SLA)
